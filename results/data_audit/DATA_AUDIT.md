# Official data and partition audit

The downloaded source is Anderson, Walsh, Subedi and Walsh, *Mango DMC and spectra Anderson et al. 2020*, [Mendeley Data version 3](https://data.mendeley.com/datasets/46htwnp833/3), DOI 10.17632/46htwnp833.3. The official CSV is `NAnderson2020MendeleyMangoNIRDataV3.csv`, 35,273,684 bytes, SHA-256 `1e0e450417ed96b47b3808556706afa84a2e6441a76e380a8b64b18d85fddee1`, under CC BY 4.0. Its hash matches the live provider file listing. Official record and listing responses are cached in `data/provenance/record_v{3,4,6}.json` and `files_v{3,4,6}.json`.

The version 4 page states that its v3 file is unchanged from version 3. The resolved version 4 listing currently returns the original filename and file ID; version 6 lists `MangoDMC_NIR_Data_v3.csv` under another file ID but with the identical content hash and byte count. This is stronger evidence of content identity than the filename alone. No expanded multi-instrument dataset was downloaded or counted as independent replication. The initial guessed API paths returned 403/404; inspecting the provider's public web client revealed the correct snapshot and files endpoints. The successful listing endpoint is `https://data.mendeley.com/public-api/datasets/46htwnp833/files?folder_id=root&version=3&$start=0&$limit=1000`.

The three development seasons contain 10,243 spectra in 94 populations. These counts match the original benchmark's spectral counts. They do not represent 12,011 distinct fruit. The source supplies no fruit identifier, cheek identifier, replicate identifier, or per-row instrument serial number. The 2020 paper's 4,675 sampled-fruit count concerns its original four-season study and is a literature count, not a uniquely identified count recoverable from this CSV. This audit does not infer fruit identities from equal DM values.

The [provider's version 6 guidance](https://data.mendeley.com/datasets/46htwnp833/6) explicitly warns against random splitting, documents repeated scans, and notes a 744-sample temperature subset. Splits therefore keep source harvest populations intact, using `s{Season}_pop{Pop}`. Population values are 1–25 in season 1, 26–44 in season 2, 45–94 in season 3, 95–112 in season 4, and 128–129 in season 5. Grouping is conservative but does not establish recoverable fruit identities. New within-development splits differ from the published calibration/tuning partition and must be labeled separately from exact author replication. A population interval for season 5 would rest on only two clusters; report those populations separately rather than claiming general between-population precision.

The raw header includes 306 numeric wavelengths from 285 to 1200 nm in 3 nm steps. The provider version 3 narrative says 309–1149 nm, while versions 4 and 6 contain a 309–149 nm typographical truncation. The manufacturer [F750 specifications](https://felixinstruments.com/food-science-instruments/nir-spectroscopy/f-750-produce-quality-meter/support/) describe 3 nm sampling and approximately 8–13 nm spectral resolution. The analysis uses exactly 103 unprocessed common channels, 684 through 990 nm inclusive, at 3 nm intervals. Sampling interval is not optical resolution.

All common spectra and metadata are present and finite. No missing spectral cells were found in the raw numeric columns. No rows were removed. There are zero exact common-spectrum duplicates, zero exact metadata-plus-common-spectrum duplicates, and zero common-spectrum duplicate sets crossing seasons or harvest groups. This excludes exact copies only; it does not imply that repeat scans are independent. See `audit.json`, `duplicates.json`, and `data/processed/composition.csv` for the machine-readable results.

The available metadata comprise `Set`, `Season`, `Region`, `Date`, `Type`, `Cultivar`, `Pop`, and `Temp`. The `Temp` categories are `No`, `Low`, `Mid`, and `High`; precise temperatures are not recoverable per row. Cultivar and physiological type are available, but are not runtime policy inputs. Original papers describe the F750 interactance instrument. Walsh's author thesis, Chapter 3 methods, states that season 5 used the same instrument, and that its 320 spectral samples originate from two Northern Territory harvest populations in 2019. The locally cached author thesis PDF was verified against the live [institutional Figshare record](https://api.figshare.com/v2/articles/27208401): MD5 `1b54f6b95aa33ad558153889039754d5`. Its primary DOI is [10.25946/27208401](https://doi.org/10.25946/27208401).

The laboratory target is dry matter as a percentage of fresh weight, verified in the [2020 primary paper](https://doi.org/10.1016/j.postharvbio.2020.111202). Error is reported in dry-matter percentage points. The author thesis describes mesocarp cores from the scanned cheeks, weighing and drying at 65 °C to constant weight (48 hours). This is a laboratory compositional assay, not a taste, safety, economic, or universal harvest-readiness outcome.

The manufacturer [F750 manual](https://cid-inc.com/static/media/uploads/manuals/f750_manual.pdf), printed page 7, gives reciprocal reflectance absorbance as `Log(1/Reflectance)` and describes reference-shutter normalization and dark scans. The study's spectra are apparent absorbance in scattering fruit, not a transmission measurement or absolute absorption coefficient. The emulator uses the conventional decadic interpretation, `r=10**(-A)`. The retrieved F750 manual does not print an explicit logarithm base or expose firmware arithmetic, and no paired raw-reference intensities are supplied to independently establish the base. This is therefore a documented, standard base-10 interpretation with an unresolved instrument-specific verification limitation. Recovering exact reference/optical-response and detector profiles requires additional source information or physical measurement. A public newer AppBuilder template was located, but its SharePoint download returned HTTP 403; it was not used to assert firmware behavior.

External targets are copied as uninterpreted strings into `data/sealed/external_labels.csv`; the full original CSV also stays in `data/sealed/`. No external target summaries, selection, imputation, or target-dependent filtering were performed. External spectra and metadata are in the separate feature file. `load_development()` reads only development assays. `load_external_features()` returns `y=None`. `load_external()` requires an explicit season plus a frozen manifest with verified artifact hashes, then records a scoring-access event. These are reproducible software boundaries, not cryptographic access restrictions on a machine controlled by the same user.

The current audit inspected code and non-numerical provenance only, and did not read that study's prediction tables, external metrics, outcome distributions, model choices or interpretation. See `prior_local_reuse.json`. The current lock cannot remove earlier exposure; a fresh season is needed for stronger independent validation.
