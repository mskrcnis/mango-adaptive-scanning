## Narrow contribution and competing explanations

The defensible question is whether explicitly separating **the error correction available by completing a fixed bank** from **the excess error of that bank relative to a rich spectral model** improves decisions under seasonal mango transfer. The bank and rich reference are learned estimators, not physical truth. Therefore a bank–spectrum loss includes modeling, sample-size and regularization differences in addition to optical coverage.

The component ideas already exist: finite-response mango filter selection (Gutiérrez), adaptive spectral measurement (Huang; BAARC), learned conditional feature acquisition (Covert; Valancius), and supervised early/full loss comparisons (Jazbec). Combining these ideas with two reference predictions is **not itself evidence of useful novelty**. The same-bank two-reference versus single-rich-reference comparison is necessary to determine whether the proposed decomposition has value; hardware-selection ablations test its additional offline role. Failure to improve is a scientifically meaningful outcome.

No “first adaptive spectrometer”, “first learned stopping rule”, “first assay-relative error-gap objective”, or absolute originality claim is supported. A preliminary paper prior-art mapping is provided here; no patent claims, patent-family search or legal novelty analysis has been performed. Exact overlap in the inaccessible journal methods remains unresolved. Prototype evidence still requires actual finite-band measurements, detector/optical calibration, reproducibility, energy and timing measurements, and independent orchard/season validation.

## Source handling

Original PDFs are held locally for evidence review, not asserted to be freely redistributable. `data/literature/source_manifest.json` records URLs, hashes, content scope and download/reuse status. The Walsh thesis and metadata/XML files were recovered from the neighboring previously completed study's literature cache; Crossref metadata for the initially rate-limited articles was re-fetched in this session. The original XML caches contain bibliographic metadata only and are **not full-text evidence**. No earlier local external-prediction tables were used for this audit. Literature-reported scores are background, not new matched benchmark results. A separately documented earlier local study reused these seasons, so external novelty/untouched-test claims must remain qualified by the project data audit.

The Walsh author code was also retrieved live from the commit-specific GitHub
URL and matched the local source SHA-256 exactly. Architecture, optimization,
group-separated local fitting and departures from the original implementation
are recorded in `docs/walsh_reference.md`. `mango/walsh_reference.py` is the
adapted author-architecture baseline; the existing compact two-convolution
network is a generic secondary CNN. Neither is an exact reproduction of the
published preprocessing/split.
