# Model and scanner methods

All measured errors use dry-matter percentage points. The finite-band channel matrix is computed offline. Runtime model calls accept only acquired scalar channel readings and the availability mask; unobserved entries are replaced with the training mean before scaling and zeroed afterward. An observed zero retains availability bit one. Runtime input contains no assay, season, population, spectral reference prediction, or hidden channel.

The partial predictor is a 64/32-unit ReLU multilayer perceptron with a scalar standardized-assay output. Its input concatenates standardized acquired readings and the binary mask. It trains for 80 epochs with one randomly selected reachable partial mask per scan per epoch. All 64 masks containing the same initial two LEDs are enumerated for an eight-channel bank, including the full-bank terminal mask. Training transforms are fitted on fitting groups only. The complete-bank reference is autoscaled PLS with six components. The primary rich reference applies rowwise standard-normal-variate transformation, Savitzky–Golay second derivative (11 points, polynomial order two, 3 nm spacing), and autoscaled PLS with 12 components. These pretreatments are used only by the full-spectrum reference, never at sparse inference.

A second, adapted convolutional spectral reference uses convolutions with 8 and 16 channels and kernels 7 and 5, a factor-two average pool, and a 32-unit dense layer. It trains for 55 epochs. This is a compact Walsh-inspired reference under this study's groups and seasons, not the authors' exact code or published split. It also defines a separately labeled single-CNN-reference controller sensitivity.

For each outer fitting split, three-way grouped cross-fitting generates every controller target. Within each inner fold, the partial predictor, complete-bank PLS, rich PLS, and CNN are fitted only on its fitting groups and frozen before predicting target groups. Targets are signed differences in individual absolute assay error. Partial-to-bank gain above 0.50 point defines the proposed binary target; partial-to-rich gain above 0.50 defines the comparator. One-step signed gains are retained, including negative gains, for every unread action. The full-mask prediction dispatches to that same frozen complete-bank predictor, making terminal stop gain exactly zero.

Supervised bank construction has its own disjoint design groups. After reserving calibration groups, 15% of the remaining training groups are assigned to bank design using seed 2718; these groups are excluded from core model fitting and every inner controller-target fold. Correlation and ridge bank proposals use only their spectra and outcomes. Every candidate, including fixed banks, is fitted on the same remaining core groups. This prevents a target group's outcome from influencing its own selected feature bank. Static and ideal-point comparisons use these same core fitting partitions and independently designed bank membership. The sparse-selection baseline tunes 14 Lasso penalties using three grouped inner folds, fits a new scaler inside each inner fitting fold, then refits the selected penalty and scaler on all core fitting rows. The LassoLars solver uses the same L1 objective with a 2,000-step bound and Gram precomputation. Penalty scores, group assignments, warning counts, iteration counts, KKT residuals and primal-dual gaps are retained in each static baseline artifact.

Before static model fitting, a development-only solver audit found that coordinate-descent Lasso remained unconverged even with 50,000 iterations. The deterministic least-angle solver resolved the same objective without convergence warnings: all 42 inner fits and the final refit on the held-season-1 fitting partition had KKT residual below 2.2e-13 and primal-dual gap below 4.7e-11. Solver choice used numerical convergence only, with no selection by predictive performance. The complete unsuccessful attempts and final resolution are retained in `results/baseline_solver_audit.json`. This repair precedes external scoring and changes neither the penalty grid nor the partitions.

Controllers are separate 64/32-unit networks initialized identically, with a binary stop-gain head and one signed next-channel score per installed LED. An auxiliary nonnegative-at-inference absolute-error estimate supports the uncertainty control and lookahead baseline. The loss is binary cross-entropy plus mean-squared action gain over unread channels plus 0.25 times mean-squared absolute-error loss. Gains and errors have separate training-derived scales. Every nonterminal reachable mask has equal weight per scan; because verified fruit identifiers are absent, the main run is scan-weighted and repeated scans are isolated by documented harvest population. No invented fruit weights are used. All controllers train 25 epochs with identical initial weights, shuffled state sequences, action labels, and optimization effort. Shared representations can still produce different fitted action scores. All optimizer settings are registered in the machine-readable protocol.

Disjoint training-side harvest populations calibrate each stop head using isotonic regression on complete sequential paths. These groups are excluded from predictor and controller fitting. Development held seasons choose a fixed operating threshold. Model parameters, calibration mappings, thresholds and code are frozen before external assays are opened.

The uncertainty control thresholds a learned expected absolute error from the same acquired input and follows the proposed controller's action scores. Fixed ordering sorts unread LEDs by their mean training OOF one-step gain from the initial state. Seeded random ordering uses a reproducible permutation. Fixed-length scans follow the development-selected fixed order. Every policy starts with the same two initial LEDs and charges for them.

The non-greedy baseline is a two-step conditional-Gaussian residual-risk approximation, not an implementation of the published acquisition-conditioned oracle. A covariance with ridge regularization is fitted to standardized training channels. For each candidate first LED it simulates three conditional values, then permits the best second LED to depend on that simulated first value. Three conditional draws for the second reading estimate expected residual error after two acquisitions. It chooses the first action with lowest average predicted terminal risk, breaking ties by bank index. The terminal residual-risk model is ridge regression fitted to genuinely OOF complete-bank absolute errors, avoiding extrapolation of a partial-only error head at the full mask. All imagined future readings come from these training-only conditional distributions; the replay example's actual unread readings and assay are inaccessible. Batched evaluation groups identical masks without changing the algorithm.

The offline HTTP app and CLI use the same frozen bundle, calibration and primary scientific operating threshold. `read_channel(led_id)` is the acquisition boundary. The app's replay source and manual entry mode provide one requested reading at a time. Trace states are compared exactly with the batched scientific simulator. The distributed real development fixture intentionally omits its assay. Pulse counts and software timings are simulated effort and software timings; they do not estimate optical energy, signal-to-noise, hardware acquisition time or field accuracy.
